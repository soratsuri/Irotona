# Irotona（イロトナ）

[English](README.md) · [ダウンロード](https://github.com/soratsuri/Irotona/releases)

Irotona（イロトナ）は、CLIP STUDIO PAINT（クリスタ）の描画色を読み取り、選んだ色をコンパニオンモード経由で使用中の主色・副色に反映する Windows 向けカラーパレットです。

Andy Fang 氏と上流の貢献者による [Luma Palette for Clip Studio Paint v0.1.3](https://github.com/andyubird/LumaPaletteCSP/tree/v0.1.3) をベースに、空吊（soratsuri）が改造したアプリです。以前は Luma Palette Custom として開発していました。ペンを接地したまま色を選ぶ操作、カラーサークルと色面パレット、明度・彩度などのショートカット、スポイト連動、位置を記憶するピン留め、日本語 UI を追加しています。

## ダウンロードと初回接続

配布するポータブル EXE はコード署名されていません。Windows SmartScreen の評価警告が表示されたり、Smart App Control が未署名アプリをブロックしたりする場合があります。配布元を確認し、SHA256SUMS.txt と SHA-256 を照合してください。SmartScreen やウイルス対策を無効にしないでください。ハッシュが一致しない場合やセキュリティソフトが脅威を報告した場合は実行しないでください。

Windows x64、Microsoft Edge WebView2 ランタイム、コンパニオンモードが使えるデスクトップ版 CLIP STUDIO PAINT が必要です。主な対象は Windows 11 です。改造版の Windows 10 での動作は未確認です。[Microsoft WebView2 ランタイム](https://developer.microsoft.com/ja-jp/microsoft-edge/webview2/)

1. 公開版が利用できるようになったら、Releases の Assets から **Irotona.exe** をダウンロードします。SHA-256 と対応ソースも同じリリースに掲載します。[Irotona のリリース](https://github.com/soratsuri/Irotona/releases)
2. 自分で書き込めるフォルダーを作り、EXE を置いて起動します。ポータブル版はそのフォルダーから直接実行できます。
3. クリスタの［ファイル］→［スマートフォンを接続］を開きます。Irotona が接続するまでコンパニオンモードの QR コードを表示してください。Windows の通知領域にあるアイコンを左クリックすると接続状況を確認できます。[CLIP STUDIO 公式サポート](https://support.clip-studio.com/ja-jp/faq/articles/20220005)
4. 次回からは、クリスタの起動中に保存済みの情報で再接続を試みます。

## 色を選ぶ

クリスタを前面にして **Ctrl + Shift + F12** を押すか、設定の［パレットを表示］を選びます。ペン先を色面に接地したままドラッグし、離した位置の色を確定します。マウスでは左クリックまたは左ボタンのドラッグで操作します。

| パレットモード | 操作 |
| --- | --- |
| OKLCH | 円で色相とクロマ、スライダーで知覚的な明度を調整。新規設定の初期モードです。 |
| HSV・HSL | 円で色相と彩度、スライダーで HSV の V または HSL の L を調整。 |
| Photoshop Lab | 平面で Lab の a・b、スライダーで L を調整。 |
| 色面パレット | ［同明度中心］は取得色の明度を基準にした OKLab 平面で、右のスライダーが明度。［全明度］は色面の横が色相、縦が明度で、右のスライダーが彩度。どちらもスライダーを上に動かすと値が上がります。比較スウォッチの左半分を押すと取得色に戻ります。 |
| カラーサークル | 外周で色相を調整。中央は四角形の HSV と三角形の HLS を切り替えられます。 |

設定の［パレットのサイズ］で小・中・大を選択すると、全モードの表示サイズが切り替わります。各モードの下部には4つの一時カラースロットと巡回ボタンがあります。空のスロットをクリックすると現在色を保存、保存済みをクリックすると呼び出し、Shift＋クリックで上書き、右クリックで削除します。スロットはアプリ終了時に消去されます。巡回ボタンは M キーと同じく、有効なモードのみを順送りします。同明度中心では、設定から背景の質感や接地影も選択できます。

上部のヘッダーをドラッグするとパレットを移動できます。ピンを押すと別のウィンドウを操作しても表示を続け、ドラッグした位置を記憶します。ピン留め中に呼び出しキーを押すと、パレットの位置と色を保ったままフォーカスが移ります。ピン留め表示中にクリスタが前面にある間は、クリスタ側の描画色や主色・副色の切り替えも反映されます。ピンをもう一度押すと通常表示に戻り、**Esc** を押すとピン留めを解除して閉じます。

| 操作 | 初期割り当て |
| --- | --- |
| パレットの呼び出し・切り替え | Ctrl + Shift + F12 |
| 色相を調整 | ← ／ → |
| 明度・明るさを調整 | ↑ ／ ↓ |
| 彩度・クロマを調整 | Shift + ↑ ／ Shift + ↓ |
| 巡回対象のパレットを切り替え | M |
| 色面パレットで取得色に戻す | 未割り当て |
| パレットを閉じる | Esc |

設定の［キーボードショートカット］でキーと巡回対象を変更できます。色の調整やモード変更はパレットにフォーカスがある間に使えます。呼び出しキーの初期設定ではクリスタまたはパレットが前面にある必要があります。通常表示のパレットは外側をクリックすると閉じます。

［カラー操作の変更幅］では、色相・彩度／クロマ・明度のキー入力1回あたりの変化量を、スライダーまたは数値入力欄で設定できます。値は自動保存され、AntiMicroX などから送られるキー入力にも適用されます。

### スポイトと連動させる

1. クリスタで一時スポイトに使うキーを設定します。たとえば **Q** を割り当てます。
2. Irotona の設定で［キーボードショートカット］→［スポイト後にパレットを表示］を選び、同じキーを割り当てます。**Alt** 単独の場合は、割り当て中に押して離します。
3. クリスタを前面にし、キーを押したままスポイトへの切り替えを待ってから、キャンバスをペンでタップするか左クリックします。離した後に描画色を読み取り、ピン留め中はその位置で色を更新します。

新規設定では未割り当てです。［解除］で自動表示をオフにできます。以前の設定で Alt 連動がオンだった場合は Alt を引き継ぎます。

## 保存場所・更新・終了

- **settings.json** は設定、**session.json** は CSP のペアリング情報です。どちらも起動した EXE の隣に保存されます。session.json には認証情報が入るため、共有用 ZIP や問い合わせの添付に含めないでください。
- 更新時は、通知領域のアイコンを右クリックして［終了］し、既存フォルダーをバックアップしてから EXE を入れ替えます。同じフォルダーにある JSON ファイルを引き続き使えます。移動する場合は、終了した状態で両方の JSON ファイルを新しい EXE の隣へコピーしてください。
- パレットや設定ウィンドウを閉じても通知領域に常駐します。完全に終了するにはアイコンを右クリックして［終了］を選びます。UI の言語は日本語・英語・繁體中文から選べます。

## 困ったとき

- **接続できない。** クリスタが起動中で、コンパニオンモードの QR コードが見えていることを確認します。保存済みの接続が使えなくなった場合は、設定または通知領域から［保存済みの接続情報を消去して QR コードを検索］を選び、新しい QR コードを表示します。この操作で保存済みのペアリングが消去されます。
- **キーが反応しない。** 通知領域のアイコン、設定したキー、クリスタが前面にあることを確認します。スポイト連動では、クリスタ側が同じキーで一時スポイトに切り替わってからタップしてください。
- **設定が保存されない。** Program Files などの保護された場所を避け、書き込めるフォルダーで実行します。設定の［保存先］で実際のパスを確認できます。
- **表示位置が使いづらい。** 設定で表示位置を変えるか、ヘッダーをドラッグします。移動先を維持するにはピン留めを使います。
